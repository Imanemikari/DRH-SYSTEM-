# AGENTS.md — DRH System (E:\DRH)

## Project Overview
Electron + React + TypeScript + Vite + Tailwind HR management app ("DRH System"). Data stored in sql.js (WASM SQLite) at `%APPDATA%\DRH-System\drh_database.sqlite`. All main-process logic is in `electron/main.js` (no build step for electron).

## Build / Package / Run Commands
- Build renderer: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass; npm run build` (Vite)
- Package: `taskkill /f /im DRH-System.exe` first (avoid EBUSY on icudtl.dat), then:
  `npx electron-packager . DRH-System --platform=win32 --arch=x64 --out=./dist_electron --overwrite --ignore="dist_electron" --ignore="src" --ignore="\.git" --ignore="marketing" --ignore="landing" --ignore="\.md" --ignore="vite\.config\.js" --ignore="tailwind\.config\.js" --ignore="postcss\.config\.js" --ignore="node_modules/(?!sql\.js)" --ignore="app_err\.log" --ignore="app_out\.log"`
  - IMPORTANT: each `--ignore` must be a separate flag; combined regexes with `.md`/`*` cause "Nothing to repeat" error.
- Launch app via desktop shortcut -> `launch.vbs` -> `dist_electron\DRH-System-win32-x64\DRH-System.exe`.
- Launching exe with stdout/stderr redirect triggers tool "ChildProcess.kill" timeout — launch detached without redirect: `Start-Process "E:\DRH\dist_electron\DRH-System-win32-x64\DRH-System.exe"`
- No lint/typecheck scripts configured (only `npm run build`). Verify via `npm run build` + app launch.
